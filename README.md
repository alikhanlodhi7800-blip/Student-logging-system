# Student-logging-system

## Overview:
The Student Logging System is a Python-based Object-Oriented Programming (OOP) project designed to manage student records, attendance, logs, reports, and administrative operations.

This project demonstrates all major OOP concepts including:
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

# Features:
- Student Management
- Attendance Tracking
- Logging System
- Admin Controls
- Error Detection
- Report Generation
- Scholarship Eligibility Checker
- OOP-Based Design

# Technologies Used:

- ABC Module
